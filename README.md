# 📰 DailyNewsApp - Advanced News Aggregator

**DailyNewsApp** is a high-performance news application that aggregates real-time stories from global sources. Built with a focus on seamless scrolling and data persistence, it demonstrates the efficient use of the **Paging Library** and **Offline-first architecture** to provide a superior reading experience.

## 🚀 Key Features

- **Global News Integration:** Real-time fetching from multiple sources via **News API**.
- **Infinite Scrolling:** Optimized data loading using **Paging 3/Adapter** for a stutter-free experience.
- **Save for Later:** Bookmark and store news articles locally using **Room Database**.
- **Social Sharing:** Easily share articles with friends and on social media platforms.
- **Search Functionality:** Find specific topics or headlines instantly.

---

## 🛠 Tech Stack & Tools

- **Language:** [Kotlin](https://kotlinlang.org/) - 100%
- **Architecture:** **MVVM** (Model-View-ViewModel) with Clean Architecture principles.
- **Dependency Injection:** **Dagger Hilt** for modular and testable code.
- **Asynchronous Work:** **Coroutines** & **Flow** for reactive programming.
- **Pagination:** **Paging Adapter** to handle large data sets efficiently.
- **Local Database:** **Room DB** for persistent storage and offline caching.
- **Networking:** **Retrofit** with OkHttp for RESTful API communication.
- **UI:** **Data Binding**, **Material Design**, and **Android Jetpack** components.

---

## 🏗 Architectural Highlights

As a **Senior Developer**, I focused on these critical aspects:
- **Offline-First Strategy:** Implemented a robust caching mechanism where Room serves as the single source of truth.
- **Pagination Logic:** Optimized the memory footprint when scrolling through hundreds of news articles.
- **Modular Data Layer:** Abstracted API and Database logic to ensure the app is easy to maintain and scale.
